# Atlante Formule 1.2

Applicazione desktop PyQt6 italiana, offline, organizzata per **36 sezioni disciplinari** con icone dedicate. Contiene **988 schede**, **410 calcolatori**, **376 visualizzazioni** e **24 esempi Python verificati**.

- **Avvio:** `Avvia.cmd` oppure `dist/AtlanteFormule/AtlanteFormule.exe`.
- **Distribuzione:** `dist/AtlanteFormule-Windows-x64.zip` e `dist/AtlanteFormule-Sorgenti.zip`.
- **Materie:** [MATERIE.md](MATERIE.md).
- **Uso:** [GUIDA.md](GUIDA.md).
- **Controlli:** [AUDIT_FORMULE.md](AUDIT_FORMULE.md) e [VERIFICHE.md](VERIFICHE.md).
- **Dati personali:** `%LOCALAPPDATA%\AtlanteFormule`, esterni all’installazione.
- **Ambiente:** `.venv` Python 3.13 x64, dipendenze bloccate in `requirements-lock.txt`.

Matematica, fisica, elettronica, programmazione/OOP, algoritmi, architetture, sistemi operativi, basi di dati, Web, reti, sicurezza e AI hanno sezioni e argomenti propri. Questa pubblicazione contiene l’edizione corrente; gli archivi storici locali non sono inclusi.
